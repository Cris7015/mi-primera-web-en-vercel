# Mi primera web en Vercel

Sitio web de **GiroTotal**, un servicio técnico de lavarropas a domicilio (empresa ficticia), hecho para la materia Organización Empresarial.

🔗 **Sitio publicado:** https://mi-primera-web-en-vercel.vercel.app

## Qué tiene

- Portada con un lavarropas animado (lavado y centrifugado).
- Diagnóstico rápido: elegís el síntoma y muestra causas probables, urgencia, tiempo de reparación y qué revisar antes de llamar.
- Servicios, cómo trabajamos, preguntas frecuentes y formulario de contacto (de demostración, no envía datos).
- Diseño adaptable a celular.

## Tecnología

HTML, CSS y JavaScript en un solo archivo (`index.html`), sin frameworks ni build.

## Deploy

El repositorio está vinculado a Vercel: cada push a `main` publica automáticamente una nueva versión del sitio.
